# Project Report (IEEE format)

IEEE conference-style report for both phases of Project 21,
Flight Delay Prediction and Rescheduling (Team T022).

This is the **hand-authored submission paper** (LaTeX). It is distinct from the
top-level `reports/` folder, which holds machine-generated, regenerable outputs
(EDA figures, evaluation metrics, rescheduling artifacts).

## Files

```
paper/
├── main.tex          The full report (IEEEtran class, self-contained bibliography)
├── main.pdf          Compiled report for both phases
├── figures/          All figures referenced by the report (PNG)
└── README.md         This file
```

## Build

### Option A — Overleaf (no install)

1. Create a new project and upload `main.tex` and the `figures/` folder
   (or upload a zip of this `paper/` directory).
2. Set the compiler to **pdfLaTeX** (Menu → Compiler).
3. Compile. The `IEEEtran` class and all packages are available on Overleaf.

### Option B — Local TeX distribution

Requires TeX Live or MiKTeX (both ship the `IEEEtran` class). From this folder:

```bash
pdflatex main
pdflatex main      # run twice so cross-references and labels resolve
```

Produces `main.pdf`. With `latexmk` installed, `latexmk -pdf main` does both
passes automatically. If the class is missing on a minimal TeX Live install:
`tlmgr install ieeetran booktabs`.

## Notes

- The bibliography uses an inline `thebibliography` block, so **no BibTeX run is
  needed** — two `pdflatex` passes suffice.
- Figures are committed copies of the EDA, validation and rescheduling plots
  generated by the pipeline (`reports/figures/` and the regenerable
  `reports/evaluation/`); filenames use hyphens to stay portable in `pdflatex`.
- Phase 1 results are documented in `docs/evaluation_results.md` and
  `docs/rescheduling_analysis.md`. Phase 2 results are documented in
  `docs/dl_evaluation.md` and `docs/dl_ablation.md`, with CSVs under `reports/dl/`.
